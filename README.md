# FitLog

FitLog is a fitness workout management web app built with Next.js, TypeScript, and Tailwind CSS.

### Features
- Browse workouts
- View workout details
- Add workouts to My Plan
- Save workouts for later
- Track planned workouts


### Tech Stack
Next.js • TypeScript • Tailwind CSS • React Context API
